# Survivor Crawling Enhanced

## 简介
基于社区Mod“Survivor Crawling”修改而来。
**唯一改动**：将倒地爬行速度从原版的默认值（50）大幅提高至 999，实现“倒地飙车”的效果。
不添加任何动画，角色保持倒地姿态进行高速移动。

## 原Mod信息
- **原Mod名称**：Survivor Crawling
- **原Mod作者**：Daroot Leafstorm
- **原Mod链接**：https://steamcommunity.com/sharedfiles/filedetails/?id=1424839258
- **原Mod描述**：Allows survivors to crawl while downed if you host a local or listen server. Speed of crawl is 50

## 本版本改动
- 将 `survivor_crawl_speed` 从 50 修改为 999
- 其余逻辑、文件结构、脚本内容均保持不变

## 安装说明
1. 下载本Mod
3. 放置到`\SteamLibrary\steamapps\common\Left 4 Dead 2\left4dead2\addons`文件夹下
